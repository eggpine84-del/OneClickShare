# OneClickShare (원클릭 사내 프린터 & 폴더 공유 매니저)

> **"회사 컴퓨터끼리 프린터와 공용 폴더 연결을 클릭 한 번으로 끝내다!"**  
> 윈도우 10/11의 복잡한 제어판, 방화벽, 서비스, 레지스트리 패치(0x0000011b)를 완전 자동화한 독립 실행형(.exe) 사내 네트워크 공유 솔루션입니다.

## 핵심 기능

1. **[메인 PC] 원클릭 공유 열기**
   - 사내 네트워크 프로필 자동 전환 (`공용` -> `개인(Private)`)
   - 윈도우 탐색 7대 필수 백그라운드 서비스 자동 가동 (`FDResPub`, `LanmanServer` 등)
   - 방화벽 포트(SMB 445/139, NetBIOS 137/138, WSD 3702) 일괄 개방
   - 윈도우 10/11 인쇄 공유 오류(`0x0000011b`) 및 게스트 로그인 차단 자동 패치
   - 로컬 프린터 원클릭 공유 및 `C:\회사공용폴더` 자동 생성 (Everyone 권한 부여)

2. **[직원 PC] 사내 메인 PC 완전 자동 탐색 & 원클릭 연결**
   - 사내 네트워크(동일 서브넷 254개 IP)를 0.5초 만에 멀티스레드로 자동 스캔하여 메인 PC 감지
   - 키보드로 IP나 컴퓨터 이름을 칠 필요 없이 원클릭 연결
   - 메인 PC의 프린터 드라이버 자동 등록
   - 바탕화면에 `회사 공용폴더` 바로가기 자동 생성 및 `Z:` 네트워크 드라이브 자동 마운트

3. **원클릭 네트워크 진단 & 자동 복구**
   - 공유가 안 되거나 프린터 연결 에러 발생 시 1초 만에 시스템 환경을 자가 진단 및 복구

4. **원클릭 공유 해제 (초기화)**
   - 메인 PC를 다른 컴퓨터로 변경할 때 기존 공유를 흔적 없이 깔끔하게 닫기

## 사용 방법

### 1. 메인 컴퓨터 (프린터/자료를 공유할 PC)
1. `OneClickShare.exe`를 실행합니다. (관리자 권한 UAC 창에서 "예" 클릭)
2. 첫 번째 탭 **`[[메인 PC] 공유 설정]`**에서 공유할 프린터를 선택합니다.
3. **`[▶ 내 컴퓨터를 메인 PC로 설정 시작]`** 버튼을 클릭합니다.

### 2. 직원 컴퓨터 (공유 프린터/폴더를 사용할 PC)
1. `OneClickShare.exe`를 실행합니다.
2. 두 번째 탭 **`[[직원 PC] 공유 연결]`**로 이동하면 상단에 사내 메인 PC가 이미 자동으로 잡혀 있습니다.
3. **`[▶ 메인 PC 프린터 & 폴더 원클릭 연결]`** 버튼을 클릭합니다. (연결 완료)

## 소프트웨어 아키텍처 (FCIS & SRP 준수)

본 프로젝트는 **Functional Core, Imperative Shell (FCIS)** 패턴 및 단일 책임 원칙(SRP)을 준수하여 개발되었습니다:

```
OneClickShare/
├── config.py                 # 환경 설정 및 윈도우 네트워크 상수
├── core/
│   └── checker.py            # 100% Pure Function 비즈니스 로직 (Side-Effect Zero)
├── shell/
│   ├── network_scanner.py    # 멀티스레드 기반 사내 서브넷 고속 병렬 스캐너
│   ├── printer_adapter.py    # Windows Spooler & PrintUI 연동 어댑터
│   ├── registry_adapter.py   # UAC 관리자 권한 및 윈도우 10/11 레지스트리 패치
│   ├── system_adapter.py     # 방화벽, 7대 서비스, SMB 폴더 공유 OS 조율
│   ├── gui_tabs.py           # 4대 탭 UI 레이아웃 뷰 렌더링
│   └── gui.py                # Tkinter 메인 컨트롤러 및 비동기 이벤트 루프
├── main.py                   # 애플리케이션 엔트리포인트
└── test_core.py              # Core 순수 함수 단위 테스트 (100% Pass)
```
